# CodeNox

CodeNox is a modern Android learning application designed to help beginner developers learn programming, Kotlin, and Android development through structured and practical learning.

The goal is simple:

**Learn → Practice → Solve → Build**

## About

CodeNox combines short lessons, practical examples, quizzes, coding challenges, and project-based learning to make Android development easier to understand and practice.

Instead of only watching tutorials, users actively apply what they learn.

## Planned Features

* Structured Android developer learning path
* Programming fundamentals
* Kotlin lessons
* Jetpack Compose
* Interactive quizzes
* Coding challenges
* Fix the Bug exercises
* Mini projects
* Learning progress tracking
* Daily learning goals
* Streak system
* XP and achievements
* Official Android documentation references
* Video-based lessons

## Vision

CodeNox aims to become more than a course application.

The long-term goal is to build a developer learning companion where users can learn concepts, practice them, solve real development problems, and build projects step by step.
